# C

C was created by Dennis Ritchie at Bell Labs in the early 1970s to rewrite the Unix operating system. It is the language that modern computing is built on. The Linux kernel, Python interpreter, Ruby interpreter, SQLite, and most operating system kernels are written in C. Understanding C means understanding how computers actually work: memory addresses, pointers, stack and heap allocation, and the machine beneath the abstraction.

## Prerequisites

A C compiler is available on most systems by default:

```bash
# macOS — install Xcode Command Line Tools if needed
xcode-select --install

# Ubuntu / Debian
sudo apt install gcc

# Windows — install MinGW or use WSL
```

Verify:

```bash
gcc --version
```

## The program

Create a file named `hello.c`:

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

## Explanation

**`#include <stdio.h>`** — A preprocessor directive. Before compiling, the preprocessor inserts the contents of `stdio.h` (Standard Input/Output header) into the file. This provides the declaration for `printf`.

**`int main()`** — The entry point function. It returns an `int` — an integer that tells the operating system whether the program succeeded. The parentheses can also be written `(void)` to be explicit that no arguments are accepted.

**`printf("Hello, World!\n")`** — `printf` (print formatted) writes text to standard output. `\n` is an escape sequence for a newline. Unlike Python's `print`, `printf` does not add a newline automatically.

**`return 0;`** — Returns zero to the OS, meaning success. Any non-zero value signals an error. Semicolons terminate every statement in C.

## Running it

```bash
# Compile
gcc hello.c -o hello

# Run
./hello
```

Output:

```
Hello, World!
```

## Notes

C gives you direct control over memory, which is both its power and its danger. No garbage collector, no bounds checking, no null safety. Every security vulnerability that ends in "buffer overflow" traces back to C code that wrote past the end of an array. Learning C teaches you why those protections exist in higher-level languages — and gives you a deep appreciation for them.

# Introduction

Every programmer remembers writing their first program. It printed two words: **Hello, World!**

That tradition started in 1978 when Brian Kernighan included it as the opening example in *The C Programming Language* — the book he wrote with Dennis Ritchie. Since then, Hello World has become the universal way to verify that your environment is set up correctly and that you understand the most fundamental structure of a program in a new language.

This book walks through Hello World in 12 popular programming languages. For each one you will see:

- A brief introduction to the language
- How to install the required tools
- The complete Hello World program
- A line-by-line explanation
- How to run it and what to expect

## What you will learn

By the end of this book you will have a clear mental model of how different languages approach the same task. You will see that some languages need a class and a special entry-point method to print one line, while others need exactly one. Some require compilation, others run directly. Some use functions, others use macros. None of this is arbitrary — every design decision reflects the values and goals of the language.

## How to read this book

Each chapter is self-contained. Jump straight to the language you are learning, or read them in order to build a comparative picture. The final chapter explains how to add more languages and how to contribute back to this repository.

## This repo as a template

This repository is also a working example of a [Boring College](https://github.com/boringcollege/boringcollege) book. The structure here — a `book.yaml` file listing chapters, and a `chapters/` directory of numbered Markdown files — is everything the sync tool needs to import a book. See the `README.md` for details on the format and how to use the included Claude skill to convert your own Markdown into this structure.

## Prerequisites

No prerequisites. Each chapter tells you exactly what to install for that language. All you need is a terminal and the willingness to type two words.

Let's get started.

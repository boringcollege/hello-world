# Go

Go (also called Golang) was designed at Google by Robert Griesemer, Rob Pike, and Ken Thompson, and released in 2009. It was built to fix frustrations with C++ and Java at scale: slow compile times, complex dependency management, and verbose concurrency. Go compiles to a single static binary, has a built-in formatter (`gofmt`), and ships with a complete standard library. It is the language Boring College itself is written in.

## Prerequisites

Download Go from [go.dev/dl](https://go.dev/dl/) or use a package manager:

```bash
# macOS (Homebrew)
brew install go

# Ubuntu / Debian
sudo apt install golang-go

# Check version
go version
```

## The program

Create a file named `hello.go`:

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
```

## Explanation

**`package main`** — Every Go file belongs to a package. The `main` package is special: it is the entry point for executable programs.

**`import "fmt"`** — Imports the `fmt` package from the standard library. `fmt` stands for "format" and provides functions for formatted I/O.

**`func main()`** — The `main` function is where execution starts. In Go, the entry point is always called `main` and takes no arguments.

**`fmt.Println(...)`** — `Println` (capital P) prints its arguments followed by a newline. The `fmt.` prefix accesses the function from the `fmt` package.

Go is strict about imports: if you import a package and do not use it, the program will not compile.

## Running it

```bash
go run hello.go
```

`go run` compiles and runs the file in one step. To build a standalone binary:

```bash
go build -o hello hello.go
./hello
```

Output:

```
Hello, World!
```

## Notes

Go enforces a single canonical code style through `gofmt`. If you paste this code into any Go editor with formatting enabled, it will look identical to what you wrote. There is no debate about tabs vs. spaces in Go — tabs win, always.
